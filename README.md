# ANGELA 个人作品集

React + Vite 单页网站，PC 版心上限 1700px，包含移动端适配。

## 运行

```sh
pnpm install
pnpm dev
```

生产构建：`pnpm build`。构建产物在 `dist`。
也可使用 npm install / npm run dev；项目当前保留 pnpm 锁文件。
